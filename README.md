# Локальная панель GrizzlySMS

Небольшая веб-панель: покупает виртуальный номер через API GrizzlySMS (совместимо с SMS-Activate),
ждёт код из SMS и показывает рядом удалённый рабочий стол (веб-VNC).

## Запуск

```bash
~/Desktop/grizzly_local/run.sh
```

Скрипт сам создаст окружение при первом запуске и остановит старый экземпляр сервера, если он ещё работает.
Откройте http://127.0.0.1:5050 (или http://localhost:5050 — другие адреса сервер отклоняет). Остановить — Ctrl+C.

## Настройка (`.env`)

| Переменная | Назначение |
|---|---|
| `GRIZZLY_API_KEY` | API-ключ из личного кабинета GrizzlySMS (обязательно) |
| `VNC_URL` | Адрес веб-VNC (`http://` или `https://`), который показывается справа. Пусто — без рабочего стола |
| `VNC_PASSWORD` | Пароль VNC. Необязателен: если не задан, панель спросит его и может запомнить в браузере |
| `PORT` | Порт сервера, по умолчанию `5050` (порт 5000 на macOS занят AirPlay Receiver) |
| `FLASK_DEBUG` | `1` — включить режим отладки (только для разработки) |

Файл `.env` не попадает в git (см. `.gitignore`).

## Как пользоваться

Панель сама подключается к рабочему столу VNC (через noVNC с вашего VNC-сервера) и умеет печатать
номер и код прямо в поле, где на рабочем столе стоит курсор — без буфера обмена.

Самый быстрый сценарий (галочка «Автоввод» включена):
1. Кликните в поле телефона на рабочем столе справа.
2. Нажмите «Купить номер» — номер сам введётся в это поле. Запросите код на сайте.
3. Кликните в поле для кода — когда SMS придёт, код введётся сам.

Подробнее:

1. Укажите код сервиса (`sn` — OLX, `ab` — Alibaba, `tg` — Telegram…) и ID страны (`2` — Казахстан, `0` — Россия, пусто — любая).
2. «Купить номер» — номер появится сразу, введите его на сайте сервиса.
3. Панель проверяет статус каждые 5 сек. Когда придёт код, его можно скопировать.
4. «Ждать ещё SMS» — получить повторный код на тот же номер; «Готово, завершить» — закрыть активацию.
5. «Отменить номер» доступно через 2 минуты после покупки, деньги возвращаются на баланс.

Если страницу перезагрузить, текущая активация продолжится (хранится в `localStorage`).
Через 20 минут без кода панель предупреждает, что активация, скорее всего, истекла, и проверяет раз в 30 сек.

Формат номера (без кода страны или с ним) выбирается в форме. Без кода — для сайтов, где перед полем уже стоит +7.
Кнопки «Копировать» кладут текст и в буфер этого компьютера, и в буфер рабочего стола (там — Ctrl+V).

Если рабочий стол пишет «нет связи»: у VNC-сервера самоподписанный сертификат. Откройте рабочий стол
по ссылке «открыть в новой вкладке», примите сертификат и нажмите «переподключить».

## Безопасность

- Сервер слушает только `127.0.0.1`.
- Принимаются только запросы с `Host` `127.0.0.1:<порт>` или `localhost:<порт>` (защита от DNS rebinding).
- POST-запросы обязаны иметь `Content-Type: application/json` — чужой сайт не сможет их отправить из браузера (защита от CSRF).
